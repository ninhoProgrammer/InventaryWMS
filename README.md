# InventaryWMS

InventaryWMS is an inventory management system designed to optimize product control and tracking in warehouses.

## Features

- Product and category management
- Inventory in/out registration
- Real-time reports and statistics
- User and permission control

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/InventaryWMS.git
    ```
